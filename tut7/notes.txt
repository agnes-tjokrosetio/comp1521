----------------------
HEXADECIMAL TO DECIMAL
----------------------

0x0013
= 0000 0000 0001 0011
= 2^0 + 2^1 + 2^4
= 19

0x0444
= 0000 0100 0100 0100
= 2^2 + 2^6 + 2^10
= 1092

0x1234
= 0001 0010 0011 0100
= 4660

0xFFFF
= 1111 1111 1111 1111
= (-1) * (0000 0000 0000 0000 + 1)
= -1

0x8000
= 1000 0000 0000 0000
= (-1) * (0111 1111 1111 1111 + 1)
= (-1) * (2^15-1 + 1)
= -32768

////////////////////////////////////////////////////////////////////////////////////////////////////
-----------------
FLOATS TO DECIMAL
-----------------

Recall: (-1)^(sign) x (1 + fraction) x 2^(exp-127)

0 00000000 00000000000000000000000
sign = 0 => value is positive
exp = 0
frac = 0
=> Result = 0.0

1 00000000 00000000000000000000000
sign = 1 => value is negative
exp = 0
frac = 0
=> Result = -0.0

0 01111111 10000000000000000000000
sign = positive
exp = 127
frac = 2^-1
=> Result = 1.5

0 01111110 00000000000000000000000
sign = positive
exp = 2^1 + 2^2 + 2^3 + 2^4 + 2^5 + 2^6 = 126
frac = 0
=> Result = (-1)^(0) x (1 + 0.0) x 2^(126-127) = 1 x 1 x 2^(-1) = 0.5

0 01111110 11111111111111111111111
sign = positive
exp = 2^1 + 2^2 + 2^3 + 2^4 + 2^5 + 2^6 = 126
frac = 2^(-1) + 2^(-2) + 2^(-3) ... = 0.9999999999....
=> Result = (-1)^(0) x (1 + 0.9999999...) x 2^(126-127) = 1 x 1.99999 x 2^(-1)= 0.99999999...

0 10000000 01100000000000000000000
sign = positive
exp = 2^7 = 128
frac = 2^(-2) + 2^(3) = 0.375
=> Result = (-1)^(0) x (1 + 0.375) x 2^(128-127) = 1 x 1.375 x 2^1 = 2.75

0 10010100 10000000000000000000000
sign = positive
exp = 148
frac = 2^(-1) = 0.5
=> Result = (-1)^(0) x (1 + 0.5) x 2^(148-127) = 3145728

0 01101110 10100000101000001010000
sign = positive
exp = 110
frac = 2^(-1) + 2^(-3) + 2^(-9) + 2^(-11) + 2^(-17) + 2^(-19) = 0.627...
=> Result = (-1)^(0) x (1 + 0.627) x 2^(110-127) = 0.00001241...


////////////////////////////////////////////////////////////////////////////////////////////////////
------------------
DECIMALS TO FLOATS
------------------

Recall: (-1)^(sign) x (1 + fraction) x 2^(exp-127)

Goal: some number k, (-1)^sign x (1+frac) x 2^n, n = exp-127

2.5 = 2^1 x 1.25 = (-1)^(0) x (1 + 0.25) x 2^(128-127)
binary: 0 10000000 0100000...0000


0.375 = 2^(-2) x 1.5 = (-1)^(0) x (1 + 0.5) x 2^(125-127)
binary: 0 01111101 1000000...0000

27 = 2^(4) x 1.6875 = (-1)^(0) x (1 + 0.6875) x 2^(131-127)
= 0.6875 = 2^-1 + 2^-3 + 2^-4
binary: 0 10000011 1011000...0000

100 = 2^(6) x 1.5625 = (-1)^(0) x (1 + 0.5625) x 2^(133-127)
= 0.5625 = 2^-1 + 2^-4
binary = 0 10000101 100100...0000


////////////////////////////////////////////////////////////////////////////////////////////////////
----------------------
APPLICATIONS OF FLOATS
----------------------

extract components of floats
float a
sign = (a >> 31) & 0x1
exponent = (a >> 23) & 0b11111111
frac = (a & 0b1111...111)

given components, then combine floats
sign s, exponent e, fraction f
(s << 31) | (e << 23) | (f & 0b1111...111)
